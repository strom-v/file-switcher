# Правила для AI-агентов

## Пересборка после изменений

После любых изменений в коде **перед коммитом** обязательно запускай и дожидайся успешного завершения:

```bash
npm run typecheck   # проверка типов (tsc: main + preload + renderer)
npm test            # юнит-тесты (vitest)
npm run build       # сборка (electron-vite: main + preload + renderer)
```

Изменения коммитятся только если все три команды завершились без ошибок.
